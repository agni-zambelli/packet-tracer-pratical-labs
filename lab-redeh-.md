# REDES HIERÁRQUICAS 

Organizam os dispositivos de uma rede em camadas onde cada uma tem sua função. 
Essa divisão é feita em 3 camadas: 
- Camada de Núcleo (core) : é a camada de backbone, conectando os switches de distribuição entre si, unindo prédios, data centers e links da internet;
- Camada de Distribuição: interliga os switches de acesso, aplicando políticas de segurança, roteamento de VLANs e controle de tráfego;
- Camada de Acesso: onde os dispositivos finais se conectam (PCs, celulares, impressoras).

### Laboratório prático 
Na atividade proposta em aula, montamos uma rede hierárquica para entendermos como funciona na prática cada camada e como elas influenciam no envio de dados/mensagens entre cada dispositivo.
Configuramos e ativamos o roteador para oferecer acesso à rede;
Usamos o comando `ping ` para testar e validar a conectividade entre os dispositivos e assim a PDU ser enviada e retornada.
